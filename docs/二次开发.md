# 二次开发地图：想改哪一处，来这行找

> 这份文件是给**你（或你雇的 AI 助手）**看的：每个可替换的部分在哪、改它会影响什么、怎么验证没改坏。
> 全项目只有两个大文件：`server.py`（网页 + 编排 + 建卡）和 `fetchers.py`（各平台取数）。
> 前端零构建：`static/` 下就是原生 HTML/CSS/JS，浏览器直接跑。

## 0. 一条内容进来之后，代码走的路线

```
你丢链接
  └─ POST /api/fetch      → fetchers.detect_platform() → PLATFORMS 表 → fetch_xxx()   ← 换平台改这里
  └─ POST /api/digest     → server.digest()
        ① 判类型 note_kind：图文走图片识字 / 视频走转写 + 抽帧识字
        ② ocr_local_images() / ocr_video_frames()  → 「图片里的文字」「画面里的文字」
        ③ call_deepseek(DIGEST_PROMPT)             ← 换提示词改这里
        ④ compile_cards()                          ← 换卡片格式改这里
        ⑤ 写 raw/clips/日期-标题.md（原文 → 消化稿 → 这张原料长成的卡）
        ⑥ questions_from_digest() → append_review_tasks()  → inbox/待复习任务.json
  └─ 你改了原文           → POST /api/redigest   （重新调模型，会花钱）
  └─ 你只改了消化稿       → POST /api/recompile  （不调模型，只重长卡）
```

## 1. 爬虫 / 平台适配 —— `fetchers.py`

| 要改的东西 | 位置 |
|---|---|
| 有哪些平台、谁处理 | `PLATFORMS`（约 1147 行）：`(正则, 平台名, 处理函数)` 三元组，从上往下第一个匹配生效 |
| 某个平台改版了 | 同文件里对应的 `fetch_zhihu` / `fetch_douyin` / `fetch_xiaohongshu` / `fetch_bilibili` / `fetch_og` |
| 登录态 cookie 放哪 | `cookies/<平台>.txt`（或环境变量 `KB_COOKIE_DIR` 指到别处）。**这个目录被 .gitignore 挡住了，不会被提交** |
| 视频转写引擎 | `transcribe()`：FunASR(paraformer-zh) 优先，失败退回 faster-whisper。引擎路径三级查找：`KB_WHISPER_MODEL` → `KB-Studio/models/` → `~/kb-tools/` |
| ffmpeg 在哪 | `ffmpeg_bin()`：`KB_FFMPEG` → `KB-Studio/vendor/` → `~/kb-tools/bin/` |
| 抽几帧、每帧多大 | `sample_frames(max_frames=8)`，帧数可在「模型配置」里改 `maxFrames` |
| B 站官方脚本 | `scripts/bilibili.py`（项目自带，不依赖任何外部 skill） |

**加一个新平台的最小步骤**：① 在 `fetchers.py` 写一个 `fetch_newsite(url)`，返回
`{"ok":True,"title","text","author","url","platform","note_kind":"video|image|text"}`；
② 加进 `PLATFORMS`；③ `python tools/doctor.py` 看能力体检；④ 拿一条真链接打 `/api/fetch` 验。
`note_kind` 决定走识字还是走转写，**填错就会出现"视频只识了封面"那种事故**。

## 2. 从链接到卡片的编排 —— `server.py`

| 要改的东西 | 位置 / 函数 |
|---|---|
| 消化模板（七个节叫什么、要什么） | `DIGEST_PROMPT`（约 230 行）。**判定口径的权威版在 `skill/PROMPTS.md` §2，两边要一起改** |
| 系统人设 | `DIGEST_SYSTEM` |
| 图片识字 / 抽帧识字的提示词 | `OCR_PROMPT`、`FRAME_OCR_PROMPT` |
| 候选 → 卡片 | `compile_cards()`：概念最多 3、连接最多 2、疑问 3；四段（主张/为什么成立/边界/用在哪）缺一段就不建卡并记进 `dropped` |
| 卡片长什么样 | `write_card()`（frontmatter 模板 + 正文块）、`append_to_card()`（跨来源回填） |
| 卡名怎么起 | `card_name()`（截断规则）、`split_gloss()`、`match_concept()`（近义判定，防同一主张起两个名字） |
| 什么不许当概念 | `META_NAME`（产品名/许可证/star 数/互动数据…）+ `PROMPTS.md` 里那段禁令 |
| 原料文末那份卡列表 | `render_card_section()` 是**唯一写入方**；`strip_card_sections()` 负责先剥再写，所以重生成不会叠第二份 |
| 复习排期 | `append_review_tasks()` + `L0-L3` 分级（在 `system.md` 里，AI 会读） |
| 模型接入（OpenAI 兼容） | `call_deepseek()`：`base_url / model / api_key` 全走 `config.json` 或网页「模型配置」。DeepSeek、通义、Kimi、智谱、本地 Ollama 都是同一个 `/chat/completions` |

## 3. 排版与渲染 —— `static/`

| 要改的东西 | 位置 |
|---|---|
| Markdown → HTML | `app.js` 的 `renderMD()`：表格包 `.twx/.tw`、时间戳 `[00:12 – 00:47]` 变可点、中文按句末标点断段 |
| 正文宽度 | `app.css` 的 `--measure`（阅读页右上角三档：46em / 64em / 不限） |
| 配色、圆角、卡片类型色 | `app.css` 第 1 行 `:root{}` 那组 CSS 变量（`--brand` 是主色） |
| 品牌 / IP 形象 | `index.html` 里 `class="logo"` 那个内联 SVG（换成自己的 `<img src>` 也行）+ 上面那组变量。文字标题在 `<title>` 和顶栏 |
| 拖拽上传 | `index.html` 的 `#drop` 区 + `app.js` 里 `$('#drop')` 那一段（FileReader → base64 → `/api/import`） |
| 手机端 | `app.css` 末尾 `@media(max-width:720px)` / `400px` 两档 |

## 4. 空库骨架 —— `templates/`

第一次跑、或 `--vault` 指到一个空目录时，`scaffold_vault()` 会照着建出
`raw/ wiki/ inbox/` + `index.md log.md progress.md revision_notes.md learner_profile.md system.md`。

- **`templates/system.md` 是这套库的"宪法"**，`templates/learner_profile.md` 是你的取舍标准 —— 两个都是纯文本模板，随便改成你自己的说法，AI 的行为跟着变。
- 已存在的文件**一个字都不会动**（只补缺的）。

## 5. 改完怎么确认没改坏

```bash
python tools/doctor.py --fix-hint   # 这台机器能干什么、缺什么（21 项）
python tools/selftest.py            # 端到端 19 项：抓取/消化/长卡/复习/批注/导入/识字
python tools/lint.py                # 库体检 9 项：悬空双链/孤儿/薄卡/重复卡列表/处理日志…
```
`selftest.py` 会真的调一次你配置的模型（花一点额度），跑完自动清掉测试痕迹。
批量改库内文件前先 `python tools/clean_clips.py`（默认只演练打 diff），确认无误再加 `--apply`。

## 6. 打包给别人 —— `tools/pack_release.py`

```bash
python tools/pack_release.py                        # 只装可分发文件，默认吐到系统临时目录
```
它会**主动拒绝**任何凭据、你的知识库内容、以及任何写死的个人机器路径 —— 扫到就报错退出，不产出包。
