# 个人知识库运转手册（system.md）

> 这份文件是这套库的「宪法」。AI 助手在帮你消化内容、维护结构时，必须遵守这里的规则。
> **这是模板，随便改**：你换成自己的话、自己的取舍标准，工具的行为就跟着变。
> 卡片提炼的判定口径在 `KB-Studio/skill/PROMPTS.md` §2，两边说的是一回事。

## 0. 核心哲学

**人只负责两件事：扔原料、提问。AI 负责维护结构。**

收藏本身不是问题，问题是没有给收藏的内容一个「被再次遇见」的入口：

```
丢链接/粘正文 → 抓成 Markdown 原料(raw/) → AI 消化成概念·连接·问题(wiki/)
        ↑                                                        ↓
   复习队列提醒 ←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←
```

痛点从来不是"存不下来"，是"存了再也不看"。所以这套库把**再遇见一次**当成硬要求：
每次消化都产出疑问，疑问排进复习队列，队列勾了才算过。

## 1. 目录职责

| 目录 | 是什么 | 谁能改 |
|---|---|---|
| `raw/clips/` | 原料：原文 + 消化稿 + 这份长成的卡 | 原文只有作者的话；消化稿可重生成 |
| `raw/assets/` | 原料带下来的图片 | AI |
| `wiki/concepts/` | 概念卡（知识块，会长大的页） | AI 建，人改 |
| `wiki/connections/` | 连接卡（新东西接到已有认知上） | AI 建，人改 |
| `wiki/questions/` | 问题卡（读完仍然没想清楚的） | AI 建，人改 |
| `inbox/` | 批注、待复习任务、回收站 | 工具 |
| `learner_profile.md` | 你的关注方向 | **只有你本人** |

## 2. 硬规则

1. 抓不到就说抓不到，并给出下一步（补 cookie / 粘正文 / 换通道）。**禁止编造原文、数据、作者。**
2. 每张原料保留 `source` / `platform` / `author`：署名既是合规，也是你回头判断可信度的依据。
3. 「原文」一节是作者的话，AI 不许改写；「消化稿」和 `wiki/` 由 AI 维护，可以重生成。
4. **同名卡只追加不覆盖，从不硬删**（删除一律进 `inbox/trash/`）。
5. 处理过程不进正文：重跑时间、备份路径、用了哪个引擎，那些属于 `log.md`。
6. 一个主张只留一张卡。新内容在印证已有概念时走「并入」，不另起近义名字。

## 3. 分级（读到哪就停）

| 级 | 标准 | 时间 | 复习 |
|---|---|---|---|
| L0 | 知道它存在 | 5-15min | +3 天快速回顾 |
| L1 | 能定位：解决什么问题、与我何关 | 30-60min | +3 天（**大多数内容到此**） |
| L2 | 能使用：讲出主张、证据、局限 | 2-4h | +1 天精读批注、+7 天自测 |
| L3 | 能复述、能扩展 | 半天+ | +1/+3/+14 |
