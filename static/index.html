拖动节点可重排；点击节点打开卡片。节点大小 = 连接数
拖动节点排布 ｜ 拖空白平移 ｜ 滚轮缩放 ｜ 单击（不移动）打开卡片

消化一条链接

粘贴链接 → 抓正文 → AI 提炼 → 自动长出概念 / 连接 / 问题三层卡，原料只增不改。

或者

「先探一下」只读不写：先看清这条链接能不能读、能读回多少字，再决定消化。

模型配置（接你自己的 API）

OpenAI 兼容都行：DeepSeek / 通义 / 小米 MiMo / Kimi / 智谱 / OpenAI / 本地 Ollama。 不配也能用——那时 AI 提炼退化成规则抽取，抓取入库照常跑。

Cookie 通行证（被登录墙挡住时才需要）

浏览器确认已登录该平台 → F12 → Network → 刷新 → 点第一个请求 → Request Headers 里整串复制 Cookie: 后面的值贴进来。
支持四种粘法：请求头整串 / 折行粘贴 / cookies.txt(Netscape) / 插件 JSON 导出。
只写进本机 cookies/（已在 .gitignore 里），不进笔记、不上传、接口只回元信息。
