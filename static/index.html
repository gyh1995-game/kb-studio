模型配置

OpenAI 兼容接口
温度 temperature
模型输出的随机程度。0.1 更保守、复现性强；0.7 以上更发散。消化素材要贴着原文走，默认 0.3 即可，除非你希望它多做一些改写。
输出上限 maxTokens
模型单次回答的长度上限（含它自己的思考过程）。太小时消化稿会写到一半被截断，通常表现为「卡片少了几段」。素材很长、或提示「被 max_tokens 截断」时，把它从 6000 调到 12000–20000。
抽帧上限 maxFrames
视频里最多截多少帧交给模型识字，默认 6。数值越大越容易抓到画面里的表格和字幕，代价是更慢、更费 token。只影响视频类素材。

Cookie 通行证

仅在被登录墙阻挡时需要

浏览器确认已登录该平台 → F12 → Network → 刷新 → 点第一个请求 → Request Headers 里整串复制 Cookie: 后面的值贴进来。支持四种粘法：请求头整串 / 折行粘贴 / cookies.txt(Netscape) / 插件 JSON 导出。仅写入本机 cookies/（已在 .gitignore 内），不进笔记、不上传，接口只回元信息。

Cookie 内容
